# Серверный скрипт для Google Таблицы (v2)

Сайт хранит все данные в Google Таблице и общается с ней через этот скрипт
(Google Apps Script, файл `Code.gs`). После установки таблица и сайт
синхронизируются в обе стороны:

| Где изменили | Что произойдёт |
|---|---|
| На сайте: регистрация, запись на курс, пройденный урок, правка в админ-панели, обращение | Сразу записывается в таблицу |
| На сайте: избранное и заметки к урокам (у вошедших) | Листы `favorites` и `notes`, видны на любом устройстве |
| В таблице руками: текст курса, новый урок, статус, роль пользователя | Видно на сайте при следующем открытии страницы (браузер держит копию не дольше 30 секунд; кнопка «Обновить данные» в админ-панели сбрасывает её сразу) |

## Установка (10 минут)

1. Откройте таблицу → **Расширения → Apps Script**.
   Если там уже есть прежний скрипт — замените весь его код содержимым `Code.gs`.
   Если проект пустой — вставьте код в файл `Code.gs`.
2. Сохраните (💾), в списке функций выберите **setup** → **Выполнить**.
   Google попросит разрешение на доступ к таблице — разрешите
   («Дополнительные настройки → Перейти к проекту»).
   Функция создаст недостающие листы (`feedback`, `sessions`) и столбцы и
   напишет в журнале, кто сейчас администратор.
3. Опубликуйте веб-приложение:
   * **Если скрипт уже был опубликован** (адрес есть в `js/config.js`):
     **Начать развертывание → Управление развертываниями → ✏️ (изменить) →
     Версия: «Новая версия» → Развернуть**. Адрес останется прежним,
     править сайт не нужно.
   * **Если публикуете впервые**: **Начать развертывание → Новое развертывание →
     Тип: Веб-приложение**, «Выполнять от имени: **меня**»,
     «У кого есть доступ: **все**» → Развернуть. Скопируйте адрес
     (`https://script.google.com/macros/s/…/exec`) в `apiUrl` в `js/config.js`.
4. Откройте сайт, войдите заново (старые входы без сессии сбрасываются один раз)
   и зайдите в админ-панель → «Обзор»: там должно быть «Apps Script v2».
5. Там же нажмите **«Перенести каталог в таблицу»**: 22 встроенных курса сайта
   (с уроками и тестами) появятся в листах `courses`, `lessons`, `questions`.
   С этого момента сайт показывает курсы **только из таблицы**: что удалили или
   сняли с публикации в таблице — пропадает и с сайта. Файлы `data/` остаются
   запасной копией на случай, если таблица недоступна. Ссылки, прогресс и
   избранное сохраняются (id курсов вроде `html-basics` не меняются).

> После **каждого** изменения `Code.gs` нужно снова сделать шаг 3
> (новая версия того же развертывания) — иначе сайт работает со старым кодом.

## Администраторы

Администратор — пользователь, у которого в листе `users` в столбце `role`
написано `admin`. Второй способ: в Apps Script → ⚙️ **Настройки проекта →
Свойства скрипта** добавьте `ADMIN_EMAILS` со списком email через запятую.
Новые пользователи всегда регистрируются как `student`.

## Как редактировать курсы прямо в таблице

* **courses** — один курс в строке. Чтобы курс появился на сайте, в `status`
  должно быть `published` (`draft` — черновик, скрыт). `id` можно не заполнять —
  скрипт проставит номер сам.
  Необязательные столбцы:
  * `stage` — готовность: `full` (полный курс, после прохождения выдаётся
    подтверждение), `demo` (открыта часть уроков), `outline` (только программа);
    пусто = `full`;
  * `access` — `open` (уроки читаются без регистрации) или `enroll`
    (после входа и записи на курс); пусто = `enroll`;
  * `subtitle`, `format`, `hours` (часов занятий), `order` (место в каталоге),
    `featured` (`да` — показать на главной), `tags` и `next` (id следующих
    курсов) — через запятую;
  * `audience`, `requirements`, `outcomes` — каждый пункт с новой строки в ячейке;
  * `projects` — по проекту в строке: `Название | Описание | HTML, CSS`;
  * `glyph` (значок обложки, 2–3 символа) и `tone` (цвет: indigo, lime, coral,
    sky, violet, sand, ink).
* **lessons** — `course_id` (id курса), `module` (название модуля), `order`
  (порядок), `title`, `type` (`text` или `video`), `content` (Markdown:
  `## заголовок`, `- список`, блоки кода в тройных обратных кавычках),
  `video_url` (ссылка для встраивания YouTube/Vimeo/Rutube/VK).
  Урок без `content` и `video_url` показывается как «в разработке».
  Необязательно: `summary` (кратко об уроке), `minutes`, `tasks` (задания,
  каждое с новой строки), `module_summary` (описание модуля — у любого его урока).
* **questions** — `lesson_id`, `question`, `options` (варианты через `|`),
  `correct_index` (номер верного варианта, **с нуля**: 0 — первый),
  `explain` (пояснение к верному ответу, необязательно).

Листы `users`, `enrollments`, `progress`, `favorites`, `notes`, `sessions`
заполняет сайт — вручную их лучше не трогать (кроме столбца `role`).

## Избранное и заметки

У вошедших пользователей избранное (`favorites`) и заметки к урокам (`notes`)
хранятся в таблице и видны на любом устройстве. При первом входе с браузера
туда же переносится всё, что раньше сохранялось только в этом браузере.
Без входа — как раньше, только в браузере.

## Безопасность

* Лист `users` наружу не отдаётся. Публично доступны только опубликованные
  курсы, их уроки и вопросы.
* Пароли хранятся с солью (`v2$…`). Хэши прежнего формата принимаются при входе
  и сразу заменяются новыми.
* Изменять таблицу через API может только администратор — это проверяет сервер.
* Таблицу саму по себе не открывайте по ссылке «для всех»: скрипту доступ
  по ссылке не нужен.
